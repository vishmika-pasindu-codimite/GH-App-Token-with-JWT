# GH-App-Token-with-JWT
# GitHub App Authentication and API Interaction Script

This script demonstrates how to authenticate with GitHub as a GitHub App, list the app's installations, and generate an access token for a specific installation. This access token can be used to perform API operations as the GitHub App.

---

## Purpose

This script is designed to:

1. Authenticate as a GitHub App using a JSON Web Token (JWT).
2. List all installations of the GitHub App.
3. Generate an access token for a specific installation to interact with the GitHub API on behalf of that installation.

It is helpful for developers managing GitHub Apps who need to automate or script interactions with GitHub repositories or organizations.

---

## Prerequisites

### GitHub App Setup
1. Create a GitHub App by following [GitHub's documentation](https://docs.github.com/en/developers/apps/creating-a-github-app).
2. Note down the **App ID** and download the private key file.
3. Ensure the GitHub App has the necessary permissions to interact with the intended resources.

---

## Dependencies

The script requires the following Python packages:

- `PyJWT` (for creating JWT tokens)
- `requests` (for making API requests)

### Installation

#### Windows
```bash
pip install PyJWT requests
```

#### Linux / macOS
```bash
pip3 install PyJWT requests
```

If you're using a virtual environment, activate it before installing dependencies.

---

## Usage

### Step 1: Prepare the Environment

1. Save the downloaded private key file from your GitHub App to a secure location.
2. Note the path to this private key file.
3. Replace the placeholders in the script with:
   - **`APP_ID`**: Your GitHub App's ID.
   - **`PRIVATE_KEY_PATH`**: Path to your GitHub App's private key file.

### Step 2: Run the Script

Run the script from your terminal or command line:

#### Windows
```bash
python script_name.py
```

#### Linux / macOS
```bash
python3 script_name.py
```

### Expected Output
1. A generated JWT token will be displayed.
2. A list of all installations associated with the GitHub App will be printed.
3. An access token for the first installation (or specified installation) will be generated.

## Troubleshooting

- **Ensure Python Version**: Python 3.6 or newer is recommended.
- **Private Key Path**: Verify that the private key file path is correct and accessible.
- **Dependencies**: Install missing dependencies using the commands above.
- **GitHub Permissions**: Ensure the GitHub App has appropriate permissions for the API operations you want to perform.

---

## Script Overview

### Functions

1. **`create_jwt`**:
   - Generates a JWT using the GitHub App's private key.
   - Used for authenticating as the GitHub App.

2. **`list_installations`**:
   - Fetches all installations of the GitHub App.
   - Requires a valid JWT token.

3. **`get_installation_token`**:
   - Generates an access token for a specific installation.
   - The access token is required to interact with GitHub resources on behalf of the installation.

---

### Example Workflow

1. Generate a JWT token.
2. List all installations of the GitHub App.
3. Generate an access token for a specific installation.
4. Use the access token for further GitHub API requests, such as managing repositories, issues, pull requests, etc.

---

## Notes

- Always keep your private key file secure.
- Avoid hardcoding sensitive information like the private key or App ID in the script.
- Tokens generated by the script have limited lifetimes. Use them promptly for API operations.
